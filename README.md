# Felix Racing Arena / 极速竞技场

Felix Racing Arena is a browser-based 3D arcade racing game built with Next.js, TypeScript, Tailwind CSS, and React Three Fiber. Players can choose cars and tracks, race through a neon virtual circuit, complete timed laps, use nitro and drift controls, and save local leaderboard results.

## Features

- 3D racing scene with a neon city track, guardrails, checkpoints, lights, and low-poly car models
- Arcade driving physics with acceleration, braking, steering, drifting, nitro, collision feedback, and off-track slowdown
- PC keyboard controls and mobile touch controls
- Race flow with setup, countdown, lap timing, checkpoint validation, pause menu, and result modal
- Garage, tracks, profile, and leaderboard pages
- Local leaderboard storage with an adapter reserved for future backend integration

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- React Three Fiber / Three.js

## Development

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:3000`.

## Build

```bash
npm run build
```
